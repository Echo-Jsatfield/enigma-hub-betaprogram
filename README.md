# 🚛 Enigma Hub — Official Beta Program

**Enigma Hub** is the official desktop companion for **Enigma Logistics**, connecting drivers, telemetry, deliveries, and career progression across *American Truck Simulator* (ATS) and *Euro Truck Simulator 2* (ETS2).

Built for the Enigma Logistics Virtual Trucking Company (VTC), Enigma Hub provides one connected workspace for tracking your driving activity and staying connected to the team.

**We Decrypt Your Logistic Needs.**

---

## 🚀 What Enigma Hub Offers

- **Live Telemetry** — Capture supported driving and delivery activity from ATS and ETS2.
- **Freight Tracking** — Record completed jobs, mileage, earnings, and delivery history.
- **ATS Road Trip** — Track supported non-freight driving activities separately from standard freight deliveries.
- **Driver Career** — Follow driving statistics, reputation, ranks, and achievements.
- **VTC Integration** — Stay connected to Enigma Logistics through the E-Hub driver platform.
- **Automatic Updates** — Receive new desktop releases through the built-in Windows updater.
- **Guided Setup** — Configure supported game installations and telemetry plugins through the setup wizard.

## 🎮 Simulator Compatibility

| Simulator / Feature | Availability |
|---|---|
| American Truck Simulator — Freight | ✅ Supported |
| American Truck Simulator — Road Trip | ✅ Supported |
| Euro Truck Simulator 2 — Freight | ✅ Supported |
| Euro Truck Simulator 2 — Coach / Bus | ⏳ Not available — TBA |
| Other ETS2 non-freight activities | ⏳ Not available — TBA |

Future feature availability is subject to development and testing. No release date has been announced for ETS2 non-freight support.

## 📦 Download & Installation

Enigma Hub is currently distributed through the official **Windows Beta Program**.

Download the latest Windows installer from the [GitHub Releases page](https://github.com/Echo-Jsatfield/enigma-hub-betaprogram/releases/latest).

The installation includes the supported Enigma telemetry components and a guided setup process to help configure your ATS and ETS2 installations.

**Automatic updating has been supported since version 1.0.3.**

### Beta Release Files

Official release assets include:

- `EnigmaHub-Setup-X.Y.Z.exe` — Windows installer
- `EnigmaHub-Setup-X.Y.Z.exe.blockmap` — Update support file
- `latest.yml` — Automatic update metadata

These files are generated and published through the official release pipeline.

**Linux desktop builds are no longer distributed beginning with version 1.0.63.** This does not affect Enigma Logistics' servers or backend services.
